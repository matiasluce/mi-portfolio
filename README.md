# Portfolio de Matías Lucero

Sitio personal one-page en HTML, CSS y JavaScript. La especificación está en [`docs/documentacion_inicial.pdf`](docs/documentacion_inicial.pdf).

## Ver en local

Abrir `index.html` en el navegador, o servir la carpeta:

```bash
python -m http.server 8000
```

## Estructura

```
index.html
css/styles.css
js/main.js
assets/img/      capturas y foto de perfil
assets/icons/
docs/
```

## Pendientes

- Textos definitivos y foto de perfil.
- Capturas y enlaces reales de los proyectos.
- Correo o WhatsApp, o servicio de formulario (`CONTACT_EMAIL` en `js/main.js`).
- Paleta final y dominio propio.
- Open Graph: imagen y URL al publicar.
